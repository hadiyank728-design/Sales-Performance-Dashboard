# 📊 Sales Data Analysis & Dashboard — Excel

### 👩‍💻 Created by Hadiya Sherin

An interactive **Sales Data Analysis Dashboard built using Microsoft Excel** to analyze sales performance, profit, categories, regions, and monthly trends.

This project demonstrates practical Excel skills including **data cleaning, formulas, PivotTables, KPI analysis, slicers, and dashboard design**.

---

## 📌 Project Overview

The project starts with raw sales data and transforms it into a clean, structured dataset for analysis.

The Excel workbook contains:

* 📋 Raw Sales Data
* 🧹 Cleaned & Prepared Data
* 📊 Pivot Table Analysis
* 📈 Interactive Sales Dashboard
* 🎯 KPI & Performance Analysis

---

## 📂 Workbook Structure

### 1️⃣ Raw Data

Contains the original sales records with information such as:

* Order ID
* Order Date
* Customer
* Product
* Category
* Region
* Quantity
* Unit Price
* Discount
* Payment Mode
* Sales
* Cost
* Profit

### 2️⃣ Clean Data

The raw dataset is cleaned and enhanced with additional calculated fields, including:

* Month
* Month Number
* Profit Margin %

### 3️⃣ Pivot Table

PivotTables are used to analyze:

* Monthly Sales & Profit
* Sales by Category
* Profit by Category
* Sales by Region
* Profit by Region

### 4️⃣ Dashboard

An interactive Excel dashboard presents the analysis in a visual and easy-to-understand format using:

* 📌 KPI Cards
* 📊 Charts
* 🎛️ Slicers
* 📈 Sales & Profit Trends
* 🗂️ Category Analysis
* 🌍 Regional Analysis
